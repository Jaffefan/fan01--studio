阿里 Qwen-UI-Agent：让 AI 真正'会用'屏幕

阿里发布 Qwen-UI-Agent，一个以真实世界为中心的 GUI 智能体基座模型，覆盖移动端、电脑端、网页端及深度搜索。在移动端 MobileWorld 基准上领先 GPT-5.6 Sol 等旗舰模型，真机基准 MobileWorld-Real 达 92.2%。模型支持跨应用操作，如在高德查地址、大众点评选店、小红书看推荐。内置安全机制，敏感操作主动停手。支持 100+ 真实手机、150+ 应用环境训练，并能在超长轨迹上在线强化学习。
AI 会用了，但更要知道何时停手。

Claude 全面开放 Computer Use，智能体落地

Anthropic 宣布 Computer Use、Skills API 与 Files API 在 Claude Platform 全面可用，并新增浏览器操作工具。Computer Use 允许 AI 看屏幕并模拟点击、输入、滚动，操作任何软件。Skills API 使智能体可调用团队定义的技能，Files API 则能返回生成的文件。这标志着 AI 从对话助手升级为能执行实际操作的数字员工，可能革新 RPA 行业并改变人们使用软件的方式。

ChatGPT 新增 Apple Messages 插件，替你发短信

OpenAI 推出 Apple Messages 插件，允许用户连接短信收件箱到 ChatGPT，实现消息的分类、分析、编辑、删除、草拟和发送。插件还兼容 Codex 和 ChatGPT Work，可用于专业场景。OpenAI 声称插件本地运行，不建立消息索引，但细节未明。该功能引发隐私担忧，OpenAI 建议用户不开启永久授权，保留最后审查机会。此举标志着 AI 开始介入最私密的通讯领域，对社交应用和用户信任体系构成挑战。

研究称三分之一的网页由 AI 撰写，你正被 AI 包围

皮尤研究中心研究发现，自 ChatGPT 发布后，超过三分之一（35%）的新网页显示出 AI 创作的痕迹。基于 Common Crawl 对近 50 万英文网页的分析，2026 年 7 月的随机样本中，10% 的网页有明显 AI 创作特征。.com 域名的 AI 创作比例是 .edu 和 .gov 的 10 倍。研究还指出 AI 写作的典型特征如 em 破折号和特定句式在增加。结合 Cloudflare 报告机器人流量超过人类，互联网可能正形成 AI 生成内容被 AI 爬取再生成的循环。
真假难辨的互联网，更显真人创作之贵。
