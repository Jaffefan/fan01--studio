OpenAI 首次评定模型达到「危险」级别

OpenAI 宣布其模型 Astra 达到网络安全「Critical」能力阈值，这是首个获此评级的模型。Astra 能在无人干预下发现未知漏洞并构建利用链，OpenAI 已加强防护并限制高级功能发布。此举引发对 AI 安全与治理的讨论，OpenAI 强调将谨慎推进，但 Reddit 用户担忧其潜在风险。

Anthropic 发布 Fable 5.1，性能再升级

Anthropic 发布 Claude Fable 5.1 与 Mythos 5.1，支持 1M token 上下文，缓存读取价格降低 75%。第三方评测显示 Fable 5.1 在智能指数上登顶，但每任务成本较 Fable 5 高 20%，因其输出 token 使用量大。Anthropic 正押注于长时运行的智能体应用，通过成本优化吸引开发者。
性能提升一分，成本可能飙升，但缓存降价是真正的甜头。
