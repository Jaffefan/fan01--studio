小米MiMo突破1000 tokens/s

小米MiMo与TileRT_AI联合发布MiMo-V2.5-Pro-UltraSpeed，首次在单台8-GPGPU标准节点上实现1万亿参数MoE模型超过1000 tokens/s的输出速度。该突破未依赖Cerebras或Groq等专用硬件，而是通过动态稀疏计算优化GPU利用率。API定价仅为3倍，输出体验提升约10倍，限时免费体验申请从6月8日至23日。该技术有望降低实时AI推理成本，加速AI应用普及。
标准硬件，破局利器。

苹果第三代AFM模型发布

苹果发布第三代Apple Foundation Models，包括两个设备端模型（AFM 3 Core及AFM 3 Core Advanced，后者为200亿参数稀疏模型）和三个服务器模型（AFM 3 Cloud、ADM 3 Cloud图像模型、AFM 3 Cloud Pro）。与Google合作定制，采用Private Cloud Compute隐私架构，支持设备端多模态功能和高精度听写，模型存储于闪存，按需加载至DRAM。
隐私不是口号，是架构。

高德发布3D原生城市世界模型

阿里巴巴旗下高德发布全球首个3D原生城市世界模型ABot-Earth0.5，覆盖190多个国家和地区。用户输入卫星图或文字，10分钟内即可在消费级GPU上生成公里级3D城市场景，输出可编辑3DGS格式，直接导入Unity等引擎。制图成本为传统百分之一，效率提升千倍，适用于具身智能、低空经济、应急救援等场景。已开放内测申请。

OpenAI向SEC提交IPO草案

OpenAI近日向美国SEC机密提交了S-1草案（首次公开募股注册声明），公司表示尚未决定上市时间，因为作为私营公司在某些事项上更有优势。声明依据1933年证券法Rule 135发布，不构成出售要约。该举措被视为OpenAI为未来融资和扩大影响力做准备，但上市时间仍存不确定性。
上市是工具，不是终点。

奥尔特曼宣布第三发展阶段
