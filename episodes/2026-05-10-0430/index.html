1. Snyk 实时拦截 AI 写出的漏洞
AI 生成代码的速度，必须慢于安全扫描。
Snyk 推出了与 Claude Code 集成的实时安全扫描插件。数据显示 Anthropic 的模型在无安全提示时只有 56% 代码安全；AI 引入 XSS 的概率是人工的 2.74 倍。Snyk 通过 MCP 方式嵌入开发者终端，每段 AI 生成的代码都会被即时扫描并自动修复。文章指出，随着企业 65-70% 的代码由 AI 生成，将安全能力内置到开发流程中而非事后补救已成为刚需。

2. YourMemory 用图神经网络记住关联事实
记忆不是存得越多越好，而是忘得越对越好。
开源项目 YourMemory 提出了一种基于图神经网络的 AI 记忆方案，解决了传统向量搜索无法关联跨实体事实的问题。在 HotpotQA 数据集上，加入实体图后双事实同时召回率从 59.5% 提升至 71.5%；在 LongMemEval 上完整会话召回率达 84.8%。系统还具备自动衰减和修剪机制，模拟人类记忆的遗忘与强化过程。所有检索和衰减均在本地运行，无需 LLM API 调用。

3. Draft 插件终结 AI 助手的「记忆丧失」
AI 助手的上限不是它能写多快，而是它能记住多少。
Draft 是一个针对 Claude Code、Codex CLI 和 Cursor 的开源插件，旨在解决 AI 编程助手在新会话中丢失产品上下文的问题。通过一个命令即可初始化，在每次新 session 启动时自动注入包括公司、产品、团队优先级和最近决策在内的完整上下文。它还通过 append-only 日志和持久化索引来防止上下文随时间过时，使 AI 始终基于最新信息工作。目前仅支持 macOS 和 Linux。

4. GitHub 项目用 AI 助手复现 58 篇论文
复现 35 年的论文，只需一个 AI 助手。

5. Coinbase 裁员 14%：AI 让工程师几天干完几周活
裁员不是因为你不值钱，而是因为你的产出可以用更少的你来完成。
Coinbase 宣布裁员 14%（约 700 人），CEO Brian Armstrong 指出 AI 让工程师效率大幅提升，过去数周的工作现在几天即可完成。公司正转向「AI-native」组织，通过减少管理层级、推行「玩家教练」管理者和实验「一人团队」结构（一人兼任工程、设计、产品）来重塑业务。2026 年初科技行业裁员总数已超 5.2 万，同比增加 40%。
