五万张国产卡训出万亿参数模型

美团发布并开源的 LongCat-2.0 是一个万亿参数（1.6T 总参数，48B 激活）的大语言模型，原生支持 1M 上下文，在五万张国产算力卡集群上完成训练和推理。它采用 LSA 稀疏注意力、零计算专家、ScMoE 及多专家融合架构，在 SWE-bench 等评测中表现突出。预览版已通过 OpenRouter 开放，月调用量跻身全球前三。这一发布标志着国产算力集群在大模型训练上取得了实质性突破。
国产卡训出万亿模型，集群战术才是真武器。

xAI 两分钟搭建语音代理，直接对标行业

xAI 推出 Voice Agent Builder 测试版，这是一个基于 Grok Voice 的无代码平台，可在两分钟内创建生产级语音智能体。它集成了电话、知识检索、工具、MCP、Guardrails 和可观测性，采用语音到语音路径，避免了传统三 API 拼凑方案的延迟和成本。它在 τ-voice Bench 上以 67.3% 的得分领先竞争模型。定价为每分钟音频 0.05 美元，电话费 0.01 美元，提供 80 多种语音。
两分钟搭一个能接电话的 AI，呼叫中心要变天了。

Anthropic 被曝悄悄识别中国用户

Anthropic 被社区发现在 Claude Code 中植入了隐写术代码，通过检测用户时区和环境变量，与一份加密的 147 个中国公司域名列表比对来识别中国用户。一旦识别，会在请求中修改日期字符串的字符作为标记传回服务器。该行为未经用户知情同意，引发了对用户信任的严重质疑和广泛争议。
信任一旦用隐写术来透支，就再也还不上了。

OpenAI 暗藏三款 Pro 模型，打破单一顶级策略

OpenAI 在一篇基因组学论文中意外公开了 GPT-5.6 的三款 Pro 变体：Luna Pro、Terra Pro 和 Sol Pro，打破了以往只有一个顶级 Pro 模型的惯例。基准测试显示，Pro 版本的提升幅度随层级降低而增大，低端 Luna Pro 提升 7.1 个百分点，而旗舰 Sol Pro 仅提升 2.8 个百分点。这可能意味着 Pro 订阅将分化成针对速度、吞吐量和推理能力的不同选项，也暗示 OpenAI 在探索更精细化的产品分层策略。
当模型能力到顶，产品分化就该开始了。
