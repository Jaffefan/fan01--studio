# Hayley Kiyoko

一首歌到一部电影，她用了十年

点击播放 00:00 / 08:54

你好，我是伊恩。

2015年夏天，一个叫Hayley Kiyoko的音乐人上传了一支音乐视频。画面里，两个十几岁的女孩在加州阳光下相遇、靠近、亲吻。歌很简单，反复唱着一句："女孩喜欢女孩，就像男孩一样。"在这之前，主流流行歌里很少听到这样的歌词——不是暗语，不是隐喻，就是直白地说了一句很多人都觉得理所当然、但没人敢写在歌里的话。

到今天，这支视频在YouTube上累计1.63亿次播放。评论区里，成千上万的女孩留言说，她们第一次在屏幕上看到自己。她们说，希望有一部长电影能讲这样的故事。

Kiyoko看到了这些留言。她当时25岁，刚发行首张专辑，在业内算个新人。但她给自己种下了一个念头：我要拍一部这样的电影。她觉得这事不难——题材摆在那，受众摆在那，连故事都有人帮她写好了，就是那支MV，把它扩展成长片不就行了？

她后来才知道，自己想得太简单了。

接下来的十年，她一直在"说服"。说服投资人，说服制片厂，说服那些手握绿灯权的人：同性恋女孩的故事不是小众，不是边缘，不是"niche"。她说，"我是有色人种的酷儿女性，我的故事是主流的。有数百万像我一样的人，我们需要的不止是两只手就能数完的故事。"

她说的"两只手"，指的是那些年屏幕上的同性恋角色。2015年到2020年间，好莱坞有同性恋主角的电影不到三十部，其中讲女同性恋的、讲有色人种女同性恋的，更是少之又少。

这条说服之路走了快十年。2023年，Kiyoko把MV里的两个女孩写成了小说。然后，它吸引了Focus Features的注意。今年6月19日，电影《Girls Like Girls》在全美公映。

电影说的是2006年，16岁的Coley经历母亲去世，跟父亲搬到俄勒冈一个小镇。她认识了邻居Sonya，两人迅速成为最好的朋友，然后暧昧、亲吻。但Sonya有一个男朋友，她无法接受自己的感情。她推开Coley，说这是"错的"。Coley独自消化那些痛苦，打工、和父亲和解，最后跟Sonya面对面，把话说开。那场戏，Kiyoko要求两个演员演成"你不知道她们之间会怎样"的感觉。她说："我忘了自己在片场，我在看一部电影。"

Coley由Maya Da Costa饰演，Sonya由Myra Molloy饰演，两个都是亚裔演员。对Kiyoko来说，这也不是偶然。她自己就是日裔美国人，她坚持"这部电影里必须要有人看得到我"。

甚至连2006年这个年份都很重要。Kiyoko说，电影里的那些细节——用IM聊天、在卧室听iPod、穿低腰牛仔裤——都是她真实的高中记忆。当时还没有智能手机，没有社交媒体，喜欢一个人要鼓足勇气走到她面前。紧张、笨拙、美好。

当然，这部电影不是完美无缺。评论里有人说，它节奏太慢，情节太淡，像一部横跨十五年的MV。但更多人看到的是不一样的东西。片中有一句台词，是Coley的爸爸告诉她："你妈妈去世的时候，她其实不完全了解你。"Kiyoko说，这句话来自她自己的妈妈。她妈妈的妈妈去世得很早，"如果她当初也是同性恋呢？永远没有一个机会让妈妈真正认识完整的自己——这种痛，我想放进电影里。"

但说实话，这部电影本身不足以解释这十年。真正让人好奇的是：为什么一个已经有流量、有受众、有影响力的故事，要从2015年等到2026年才能上映？

这不是Kiyoko一个人的问题。

在好莱坞，同性恋电影历来面临一种"玻璃天花板"。不是不能拍，是拍了不赚钱。《断背山》得了金狮奖、奥斯卡，全球1.78亿美元票房。但之后几年，大制片厂并没有批量生产同性恋故事。2010年代，独立电影是主要阵地，但大部分是小成本、小范围上映，像《月光男孩》那样的突破是个例外。

2017年以后，电视端开始发力。《女子监狱》《姿态》《性教育》，流媒体平台让更多角色得以出现。但大银幕上，女同性恋为主角的电影仍然屈指可数。2019年的《燃烧女子的肖像》算是现象级作品，但它是法国片、历史题材、艺术片，跟当下美国青少年的生活隔了一层。

Kiyoko想拍的不是历史，不是悲剧。是青少年爱情，有痛苦、有美好、有阳光和眼泪。她说，"我不想要那些悲伤的、被惩罚的结局。我想讲一个女孩爱上另一个女孩，然后一切都可以好好的。"

但这恰恰是最难卖的概念。制片厂觉得没有冲突——"没有冲突怎么拍电影？"Kiyoko花了多年才明白：对很多人来说，光是存在本身就是冲突。一个女孩发现自己喜欢另一个女孩，已经足够构成叙事。

直到2023年，情况开始松动。那一年，《芭比》全球票房破14亿美元，导演格蕾塔·葛韦格证明了女性叙事可以有多大的商业潜力。同年，一些独立制片厂开始主动寻找"酷儿浪漫喜剧"。Kiyoko的小说正好赶上这个窗口。

Focus Features接了这部电影。选角时，Kiyoko用了两个关键决定：第一，两个女主角都是亚裔；第二，不要那种“出柜即痛苦”的套路。她说，"我没有时间再等十年才看到另一个像我这样的女孩出现在屏幕上。"

但电影上映之后，更大的问题浮出水面。

结构性的困境

——即便绿灯通过，后续的发行和宣传往往还是“差异化对待”。行业内有一种默认：同性恋题材的电影不需要大范围上映，靠口碑和线上就行了。

这跟十年前的音乐视频是一样的处境：有观众，但没渠道。有需求，但没供应。Kiyoko用十年时间从MV走到银幕，但下一个十年呢？当一部同性恋电影不再被认为是“突破”，而只是“一部电影”的时候，才是真正的进步。

电影结尾，Coley和Sonya没有明确说在一起。她们站在一起，看着窗外。Kiyoko觉得，这样就够了——"她们是彼此故事的开头，不是结尾。"

我还想说一个细节。电影上映前，Kiyoko在Instagram上发了一段视频。她站在一个电影院门口，身后是《Girls Like Girls》的海报。她看着镜头，停了几秒，然后说："我们做到了。"

声音没有颤抖，但眼睛湿了。

我也想起那条1.63亿播放量的MV。十年前，那些女孩在评论区里写自己故事。十年后，她们中可能有人已经当妈妈了，有人还在找自己。不管怎样，现在她们可以买一张电影票，坐在暗下去的放映厅里，跟着两个女孩一起笑、一起哭、一起成长。

这不是一个完美的结局。但这是一个开始。
