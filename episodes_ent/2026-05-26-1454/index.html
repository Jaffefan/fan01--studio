# 许垚

一瓶培菲康里的河豚毒素：许垚与三体宇宙的致命纠葛

点击播放 00:00 / 08:39

警方在许垚的住处和办公室搜出大量毒物：河豚毒素、鹅

你好，我是伊恩。

2020年12月16日，上海瑞金医院的急诊室灯火通明。一个中年男人被推进来，面色青紫，意识模糊。病历上写的是游族网络董事长，林奇。起初医生以为是急性肠胃炎，可常规治疗无效，病情急转直下。两天后，血液检测报告出来，结果让所有人倒吸一口凉气——河豚毒素。一种比氰化物更致命、只需0.5毫克就能致死的东西。警方迅速介入，调取监控、排查接触史。第一个人浮出水面，就是林奇的左膀右臂、三体公司CEO，许垚。

许垚，1981年生，贵阳人。西南政法大学本科，法国和美国的海归硕士，曾在国际律所和复星集团当高管。2017年加入游族，2018年出任三体宇宙CEO，全权负责《三体》IP的开发。那可是个金矿——刘慈欣的科幻巨著，全球粉丝无数。可他跟林奇的蜜月期很快就结束了。据知情人士回忆，两人在股权分配上闹得不可开交。许垚想拿更多股份，林奇不松口。财务表现不佳，公司烧钱却没爆款，矛盾越积越深。

警方在许垚的住处和办公室搜出大量毒物：河豚毒素、鹅膏毒肽、氯化甲基汞。这些不是普通的鼠药，而是需要专业知识、采购渠道和精确配比的顶级毒物。更令人不寒而栗的是，许垚不是一时冲动。证据显示，他从2020年5月开始，系统地下载科学论文，用假公章向北京、武汉、东莞的公司购买剧毒化学品。还特地在日本注册一家贸易公司，进口违禁物。他在虹桥机场附近租了个仓库当制毒工场，先拿猫狗做活体实验，确认剂量合适后才对人下手。为了隐匿行踪，他用了160多个手机号。层层隔离，环环相扣。

但他最终还是被抓住了。不仅是因为林奇的死。警方发现，许垚的投毒目标不止一人。公司里还有两名同事中了招——一个叫赵宇尧，一个叫赵骥龙，都是林奇信任的高管。赵骥龙的妻子和一名客户也遭了殃。四个无辜的人，被同一种方式伤害：通过被污染的咖啡胶囊、威士忌、矿泉水摄入氯化甲基汞。赵宇尧后来在社交媒体上说，自己至今还在接受治疗。2026年5月21日，许垚被执行死刑的消息传来，他写道：“正义，虽迟但到。”

这整件事听起来像某个黑色电影的剧本，但更让我震撼的，是许垚那些“花招”。庭审中，他辩称自己买毒是为了自杀，还拿出精神疾病的就诊记录——被捕前，他专门买了几本精神病司法鉴定的书，研究如何伪装成“精神病人”来免死。在牢里，他跟狱友密谋，让对方假装自杀，自己“救”他，想靠假立功减轻刑罚。但法官兼毫不买账。2024年3月，上海市第一中级人民法院以故意杀人罪判处死刑。2025年6月，上诉被驳回。今年5月21日，死刑执行。

这事在游戏圈和科幻迷中炸开了锅，不仅因为一条人命，更因为它勾连着一个IP的命运——《三体》。2014年，游族影业宣布要拍《三体》电影，张番番导演，冯绍峰、张静初主演。2015年1月，电影开机，但拍摄完成后，制作陷入泥潭。成片据说长达4小时，需要大改。2016年，游族老板林奇决定彻底接管，成立游族影业和三体宇宙公司，许垚就是这时候被请来的。他当时是复星集团的法务高管，林奇看中他的能力，许诺让他主导IP开发。

许垚上任后，确实做了不少事。他理顺了版权归属——刘慈欣最初把《三体》的影视改编权卖给了张番番，后来游族从张番番手中买回，再交给三体宇宙统一运营。他还推动了游戏授权、海外改编计划。2019年，三体宇宙与奈飞合作的消息传出，全球瞩目。但与此同时，公司内部矛盾加剧。据员工回忆，许垚管理风格非常强势，财权抓得很紧，林奇对他又用又防，股权始终不给。许垚越来越不满，私下抱怨“我替公司做牛做马，却连一根毛都分不到”。

类似的故事，在商界并不罕见。比如小说《教父》里，那个让迈克尔·柯里昂失去兄弟的赌场老板莫·格林，就被写成了“觊觎股权不成反被谋杀”的隐喻。现实里，这种因股权分配不公而杀人的极端案例，许垚不是第一个。1990年代台湾“新巨集团”的萧姓经理，就因分红不满意，勾结黑帮绑架老板，撕票潜逃。2017年，印度第二大软件公司Infosys的创始人，也曾因股权纠纷险遭毒手。但许垚的案子之所以格外刺眼，是因为它发生在文化创意领域——一个本该充满想象力、创作力的行业。

这让我想起《三体》小说里的一句台词：“给岁月以文明，而不是给文明以岁月。”许垚用他自己的方式，“给生命以毒药”。而那瓶被灌了毒药的培菲康——一种益生菌药瓶——成了他全部野心的终结点。

执行死刑后，很多媒体关注许垚的结局，但更耐人寻味的是《三体》IP接下来的走向。奈飞剧版第一季2024年上线，口碑两极。国内电视剧版由腾讯视频出品，2023年初播出，评价不错。游族影业还在推进电影项目，但受此案影响，资金和声誉都严重受损。2021年，新浪、字节跳动和B站都曾传出收购三体宇宙股权的消息，不过没下文。天眼查显示，三体宇宙目前的实控人仍然是林奇的亲属。

一些业内人士私下说，许垚的死未必能彻底终结这场风波。因为《三体》IP的长期运营，需要稳定的管理层和清晰的战略，而这一系列丑闻可能打乱节奏。有不少网友在社交网络上感慨，这比《三体》小说本身更像一部“黑暗森林”现实版——不是外星人来毁灭地球，而是三个人类彼此毁灭。

也有法律学者在微博上指出，许垚案本质上是顶尖法务与司法系统的对决。他以为自己能靠法律漏洞脱罪，结果被更高明的司法锁定。这给所有企业主一个个警示：契约精神比签字盖章更重要。

而我自己的感慨，也许更简单：《三体》里有一句话——'给岁月以文明，而不是给文明以岁月。'许垚反其道而行。他给生命加了毒药，却给时代留了疤痕。案子完结了，但《三体》宇宙里，再难抹去一个加害者CEO的阴影。

好，这就是今天的故事。谢谢你愿意花时间来听这个略显沉重的案子。我是伊恩，下回见。
