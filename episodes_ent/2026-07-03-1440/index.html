# Rocksteady

不再做游戏，只做一张电子表格

点击播放 00:00 / 09:48

咱们先拉回《自杀小队》这个项目本身。2017年，R

你好，我是伊恩。

2015年，《蝙蝠侠：阿卡姆骑士》发售的时候，Rocksteady是全世界玩家眼里的神。十年之后，这个工作室交出了《自杀小队：杀死正义联盟》。结果呢？华纳兄弟亏了2亿美元。最近，两位原Rocksteady的设计师对着彭博社的记者说了一番话，让我觉得，这可能是这几年游戏行业最诚实的坦白。

上周，彭博社发了一篇报道，采访了前Rocksteady首席设计师阿克塞尔·赖德比和联合设计总监约翰尼·阿姆斯特朗。这两个人都在《自杀小队》项目上熬了几年，最后带着一身疲惫离开。他们的新项目是一个叫《塞卡迪亚的秘密》的卡牌构筑独立游戏，正在Kickstarter上筹款，目标只有11000美元——这数字相比AAA大作动辄上亿的预算，小得像是开玩笑。但赖德比说了一句话，让我印象特别深。他说，做《自杀小队》做到后期，他感觉自己“不再是在做游戏，而是在遵循一张电子表格，这张神秘的市场营销分析表格，没人能清晰地呈现出来”。阿姆斯特朗也提到，团队从阿卡姆三部曲的成功过来，带着一种过度自信，直接扎进了服务型游戏这个完全不同的坑里。游戏规模太大，很多东西根本没法测试，而反复的小规模延期取代了战略性规划，导致“每个人都感觉自己是在原地奔跑”。

咱们先拉回《自杀小队》这个项目本身。2017年，Rocksteady刚完成《蝙蝠侠：阿卡姆VR》，信心满满地开始筹划下一部大作。那时候服务型游戏正是风口，华纳兄弟希望Rocksteady能做出一个像《命运》或者《全境封锁》那样的长期运营游戏，既能卖拷贝，又能靠内购和战斗通行证持续赚钱。于是，2017年正式立项。但立项之后，开发一直不顺。从2020年开始不断延期，发售日从2022年推到2023年，又推到2024年2月。2023年底，游戏进行了封闭Beta测试，玩家反馈普遍负面——角色长得丑、任务重复、必须全程联网。2024年2月正式发售后，Steam同时在线人数峰值只有13000人，远低于《霍格沃茨之遗》的87万。三个月后，华纳在财报中承认，这款游戏导致公司亏损了2亿美元。这个数字比当时多数分析师预估的还要高，而整个游戏业的亏损纪录又被刷新了一次——上一次是2019年《圣歌》的1亿多美元。

关键不是亏钱，而是怎么亏的。赖德比描述了一个场景：大会议的主题从“做什么才酷”变成了“做什么才能让玩家掏钱”。团队被要求设计一个能让玩家持续花钱的装备升级系统、一个人人都能打的通行证。而反派战利品掉落率、任务循环次数、在线留存率这些数据，变成了比剧情和玩法更优先的指标。阿姆斯特朗说，以前在阿卡姆游戏里，他们可以精心设计每个谜题、每个敌人的站位，但在《自杀小队》里，一切必须可重复、可量化，那种“用手工打磨一个游戏细节”的感觉完全消失了。

这听起来像是一个典型的“大厂扼杀创意”的故事，但如果我们把时间轴拉长，会发现这不是Rocksteady一家的问题。它是整个欧美3A游戏工业，在过去十年走向“服务型游戏”这条路的必然结果。

2014年，动视暴雪推出了《命运》，首年营收超过5亿美元，让整个行业都眼红了。紧接着，2016年《守望先锋》又靠战利品箱赚得盆满钵满。那时候，几乎所有大厂都在想：我们能不能也搞一个？EA在2017年把《星球大战：前线2》做成了开箱地狱，被骂到修改系统。BioWare的《圣歌》在2019年翻车，被称为“服务型游戏史上最大的灾难之一”。但即便知道风险，资本还是推着工作室往前走。华纳兄弟在2020年左右宣布，未来所有DC游戏都将“偏向服务型”。而Rocksteady的母公司史克威尔艾尼克斯呢？他们2021年推出的《漫威复仇者联盟》也是服务型，两年后停更，亏损超过1亿美元。

但还有一个更深层的变化：在服务型游戏模式出现之前，3A游戏是怎么赚钱的？答案是：卖拷贝。一个60美元的游戏，卖出去就是利润。但服务型游戏需要玩家持续在线、持续消费，所以必须设计“动机”——每日任务、战斗通行证、限时活动。这种设计从根上改变了游戏创作的逻辑。以前的游戏是从“关卡”出发：设计一个有趣的战斗，然后把它放进游戏里。服务型游戏是从“系统”出发：设计一套能让玩家停留300小时的成长曲线，然后在曲线上挖坑埋消费点。就像赖德比说的，游戏变成了一张电子表格。

Rocksteady这个案例特别有意思的地方在于，它的成功历史里其实藏着反例。阿卡姆三部曲的总销量超过3000万份，但那是纯粹的单机体验：一次买断，没有内购，没有联网要求。玩家喜欢它们，是因为它们提供了独特的“成为蝙蝠侠”的沉浸感。而《自杀小队》呢？它本身是一个四人的第三方射击游戏，却要强行适应服务型模式。结果就是：沉浸感没了，重复劳动来了。

从更宏观的视角看，这其实是“创意产业被数据驱动改造”的一个缩影。2010年代，Netflix用数据证明了算法推荐能产生爆款，于是所有内容公司都想学。但游戏和影视不同，游戏的核心是“玩的过程”。当“留存率”和“平均在线时长”成为考核指标时，设计者自然会把精力放在“怎么让玩家不想下线”，而不是“怎么让玩家玩得开心”。这种扭曲在《自杀小队》身上表现得淋漓尽致。

有意思的是，赖德比和阿姆斯特朗现在做的独立游戏，所有设计逻辑都是反过来的。他们说，那是一个“献给独立游戏的公开情书”——致敬《杀戮尖塔》《小丑牌》《黑帝斯》这些游戏。这些游戏没有战斗通行证，没有每日任务，甚至没有联网。但它们有一个共同点：玩法扎实，耐玩。而且他们还在Kickstarter页面上加了一条反AI生成的声明，明确表示不会使用生成式AI。这态度和现在很多大厂形成鲜明对比——EA说要用AI加速开发，育碧推出了AI写对白的工具。

说回到《自杀小队》本身。2025年，华纳正式宣布停止更新该游戏，第三季成了最后一季。此时距离游戏发售才一年半。Rocksteady工作室现在怎么样了？2024年底，华纳进行了重组，Rocksteady裁员了一部分，剩下的团队据传在做一个新的单机蝙蝠侠游戏。但消息从未被官方确认，而整个工作室的士气，可能比阿卡姆疯人院还要低。

最后，我想留下一个开放式的问题：游戏业的“服务型狂热”会不会就此到头？看看近年来的市场吧——2024年，索尼的《绝地潜兵2》大获成功，但它本质上是一个合作射击游戏，内容靠更新补充，并没有逼玩家肝通行证。而2025年最受期待的游戏之一《黑神话：悟空》，纯粹单机。好像是玩家在用脚投票。但另一边，腾讯的《三角洲行动》和动视的《使命召唤：战区》依然赚着巨额流水。资本不会轻易放弃利润。那么，未来的3A游戏，到底是会像《自杀小队》一样被电子表格扼杀，还是能找到一种平衡？我不知道。但至少，赖德比和阿姆斯特朗用自己的故事告诉我们：游戏首先是给人玩的，不是给数据看的。

这期就到这里。我是伊恩，下次见。
