# 戴夫·巴蒂斯塔

奎托斯换角风波：巴蒂斯塔接棒战神

点击播放 00:00 / 09:49

巴蒂斯塔是谁？摔角界出身，WWE的传奇人物，后来转

早上刷到一条消息，差点把手里的咖啡洒了——戴夫·巴蒂斯塔，正式接下奎托斯这个角色。要知道，上一任演员瑞安·赫斯特，可是为了这个角色增重40磅，连红色纹身都纹好了。结果，一个二头肌撕裂，全都泡汤了。今天，咱们就聊聊这出换角大戏背后的故事。

瑞安·赫斯特，这个名字可能有些人不太熟，但提到《战神》游戏里的雷神索尔，你肯定有印象。对，就是那个在《战神：诸神黄昏》里拿着锤子、一脸大胡子的壮汉，就是他演的。赫斯特是正儿八经的配音和动作捕捉演员，他在游戏里的表现，粉丝们有目共睹。所以当亚马逊宣布，真人剧版《战神》的奎托斯由他来演的时候，很多人觉得，这选角挺靠谱。

可惜，计划赶不上变化。据报道，赫斯特在拍摄一个特技镜头的时候，出了意外——二头肌撕裂。这伤有多重？医生说，这种撕裂可不是养几天就能好的，恢复期长着呢。制作组等不起。一部剧的拍摄，每一天都是白花花的银子，演员的档期、场地、设备，全都卡在那儿。如果等赫斯特伤愈，整个剧组就得停工好几个月，预算一下就爆了。所以，权衡再三，制片方做了一个冷酷但现实的决定：换人。

换谁呢？很快，消息传出来，戴夫·巴蒂斯塔在洽谈。这事儿其实不意外。半个月前，就有风声说巴蒂斯塔在接触这个项目。演员毛遂自荐，这在好莱坞不新鲜，但巴蒂斯塔的执着，确实有点意思。

巴蒂斯塔是谁？摔角界出身，WWE的传奇人物，后来转型当演员，最出名的角色是《银河护卫队》里的毁灭者德拉克斯。那个浑身肌肉、一脸呆萌的硬汉，就是他。但你知道吗？去年年底，他为了一个角色，硬是减了75磅，差不多34公斤，整个人瘦了一圈。当时新闻一出，粉丝都惊了。但现在的问题是，奎托斯是个肌肉猛男，你瘦成这样，怎么演？

不过，粉丝们似乎并不担心。消息底下，一堆人在喊：“让他增肌回德拉克斯的样子就行了！”确实，巴蒂斯塔的底子在那儿，练回去不是什么难事。但关键不是肌肉，是气质。奎托斯这个角色，游戏里的形象太深入人心了：光头、红纹身、胡须，还有那声嘶吼，粗犷、暴躁，但内心深处又有种说不出的悲凉。巴蒂斯塔能不能演出那股劲儿？

咱们先来捋捋《战神》这个IP的来龙去脉。2005年，索尼圣莫尼卡工作室推出了初代《战神》，当时惊为天人。制作人科里·巴洛格，一个胡子拉碴的中年人，带着团队把希腊神话翻了个底朝天。玩家扮演奎托斯，一个斯巴达将军，为了赎罪，替众神卖命，结果发现一切都是阴谋，最后手刃战神阿瑞斯，自己登上了神位。那游戏，爽快、暴力，又带着点古希腊悲剧的宿命感。

三代之后，奎托斯把奥林匹斯山搅得天翻地覆，众神几乎全灭。本来故事到这儿就完了，但2018年，圣莫尼卡又搞了个大的：重启。新《战神》把背景搬到了北欧，奎托斯带着儿子阿特柔斯，教他狩猎、战斗，也教他克制。这版奎托斯不再是那个暴怒的屠神者，而是一个沧桑的父亲，背着斧头，带着儿子，在冰天雪地里前行。这一转变，让老玩家泪目，新玩家入坑。游戏拿奖拿到手软，年度最佳自然不在话下。

所以，当亚马逊宣布要拍真人剧的时候，所有人都屏住了呼吸。游戏改编影视，这事儿一直都是雷区。最惨的例子，就是《魔兽世界》电影。2016年，那片子投资1.6亿美元，全球票房才4.3亿，看着还行，但口碑崩了，粉丝不买账，说跟游戏里的艾泽拉斯完全不是一回事。还有《刺客信条》，法鲨演的，也一样，票房口碑双扑街。

但也有成功的。《最后生还者》，HBO拍的，2023年播出，口碑爆棚。主角乔尔，佩德罗·帕斯卡演的。那厮也是个硬汉专业户，《毒枭》里的警探，《曼达洛人》里的头盔男。但他演乔尔，没有照搬游戏，而是加了好多细腻的内心戏，把那种失去女儿、在末世里挣扎的父亲形象演活了。粉丝看了直呼神选角。

为什么有的改编成功，有的改编失败？关键就在“还原”和“创新”的平衡。所谓还原，是形似；创新，是神似。光有胡子顶着纹身，那不行。你得让观众相信，你就是那个在荒野里教儿子射箭的糙汉。

巴蒂斯塔行不行？他的优势在于，摔角手的出身让他自带一股野兽般的压迫感。但劣势也明显，他的演技，在好莱坞一直被诟病“死板”。不过，近几年他也在努力，《银翼杀手2049》里演个复制人，戏份不多，但表情管理进步了不少。还有《沙丘2》，他演那个选帝侯的侄子，虽然没多久就被锯了，但那种阴鸷劲儿，还挺有味道。

但奎托斯不是反派，是个英雄。而且是个内心有创伤的英雄。他跟儿子的关系，是整个故事的核心。巴蒂斯塔能不能演出那种“硬汉柔情”？这对他是个考验。

其实，这不是巴蒂斯塔第一次想演游戏改编角色了。他有个心心念念的“梦想角色”——《战争机器》里的马库斯·菲尼克斯。2018年的时候，他公开喊话，说他一直在跟版权方谈，想演这部剧。甚至有一次，环球影业找他聊《速度与激情》的片约，他还抽机会推销《战争机器》。可惜，这个项目一直没影。现在《战神》找上门，算是圆了他半个梦。

至于瑞安·赫斯特，他这伤，唉，真是点背。不过，娱乐圈这种事儿，多了去了。演员因伤退演，被换角，听起来残酷，但也是行业常态。当年《速度与激情7》里保罗·沃克去世，剧组强行改剧本，用替身和CGI硬把他剩下的戏份拍完，那叫一个折腾。还有《魔戒》里演阿拉贡的维果·莫滕森，拍戏踢飞一个精灵的头盔，把脚趾骨踢断了，硬是坚持拍完，也算敬业。但像赫斯特这种，剧组直接等不起，只能换人，也挺无奈。

不过，塞翁失马，焉知非福。赫斯特虽然丢了《战神》，但他毕竟演过游戏里的索尔，那是他的高光时刻。而且他的演技，好莱坞有目共睹，以后有的是机会。倒是巴蒂斯塔，这下压力大了。粉丝的期待值可高了，万一演砸了，别说游戏迷不答应，他自己也过不去这道坎儿。

接下来，剧版《战神》预计在2026年10月中旬恢复拍摄，前期筹备这个月就启动。也就是说，留给巴蒂斯塔训练的时间，满打满算也就一年多，要练回德拉克斯的体型，还得揣摩角色。说实话，紧。

还有一件事儿，科里·巴洛格透露，新的游戏正在开发，叫《战神：劳菲》，讲的是奎托斯在希腊之外的故事。2027年2月发售。连着剧版和游戏，到时候，屏幕上和电视上，都是奎托斯的故事，你将会看到一个更完整的战神宇宙。

好了，今天的故事就讲到这儿。巴蒂斯塔能不能驾驭这个角色？时间会给出答案。但我更想说的是，游戏改编这条路，从来都不好走，既有辉煌，也有翻车。就像赫斯特的伤，你永远不知道下一刻会发生什么。但正是这种不确定性，让每一次尝试都充满了魅力。你期待这部《战神》吗？或者，你有自己心目中的奎托斯人选？欢迎在评论区聊聊，咱们下期再见。
