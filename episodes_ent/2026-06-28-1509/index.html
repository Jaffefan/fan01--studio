# 索尼

你买的电影，索尼说删就删

点击播放 00:00 / 07:16

这不是索尼第一次这么干。2023年12月，索尼宣布

你好，我是伊恩。

想象一下，你打开自己的电影库，想再看一遍《热血警探》，结果发现——它消失了。不是临时下架，不是版权到期无法购买，而是你清清楚楚付过钱、买断的那份数字拷贝，被索尼单方面从你的账户里删除了。这不是假设，这正是接下来几个月里，超过550部电影的购买者将要面对的现实。

2026年6月底，索尼通过电子邮件向PlayStation用户发出通知：从2026年9月1日起，因内容授权协议变更，你曾经通过PlayStation商店购买的Studio Canal影片将被删除。通知措辞直接：“内容将从您的视频库中移除。”没有提退款，没有提替代方案。

受影响的电影名单超过550部，索尼官网有完整列表。其中不乏知名度很高的作品：《现代启示录：终剪版》《街区大作战》《鬼玩人》《高地人》《热血警探》《帕丁顿熊》《第一滴血》《机械战警2014》《鲨卷风》《终结者2》《披头士：一周八天》等。甚至还有电视剧，比如《美国众神》第一季。

这不是索尼第一次这么干。2023年12月，索尼宣布从用户的PlayStation账户中删除Discovery内容，当时引发了巨大的负面反响。用户愤怒的是：我明明买了这些内容，为什么你说删就删？几周后，索尼改口，说Discovery内容不再删除，原因是“更新了授权安排”，并感谢粉丝的“持续支持和反馈”。当时索尼承诺至少再保留30个月——而30个月刚好在2026年6月到期。也就是说，这个月的保护期一过，索尼立刻启动了新一轮的删除。

事实上，索尼早在2021年就宣布停止在PlayStation商店出售或租赁电影和电视剧。但停止销售是一回事，删除用户已购买的内容是另一回事。

这件事的核心，是“数字所有权”这个我们已经争论了十几年的老问题。当我们说“买”了一部数字电影，我们到底买的是什么？

实际上，我们买的从来不是电影本身，而是一份有限的访问许可。用户协议里通常写得很清楚：你获得的是在特定平台、特定条件下的观看权，而非对数字文件的所有权。但问题在于，多数人不会去看那些冗长的法律条文，普通用户的理解就是：我付了钱，这东西就是我的。

这让人想起音乐领域的类似事件。2022年，苹果关闭了iTunes音乐下载服务，但用户已购的歌曲仍然保留在资料库中——苹果的做法相对温和。相比之下，索尼这种直接删除的做法更为激进。

为什么索尼要这么做？直接原因很明确：授权协议到期。Studio Canal是法国最大的电影制作和发行公司之一，索尼与它们的许可协议不再续约。但更根本的原因是，数字内容的商业模式从来就不支持“永久拥有”。版权方将内容许可给平台，平台再许可给用户，每个环节都有时间限制。一旦上游断供，下游就无法继续提供服务。

这并非PlayStation独有的问题。2022年，华纳兄弟的流媒体服务HBO Max突然下架了包括《蝙蝠女》在内的多部原创电影，甚至有些电影尚未上线就被撤下。虽然这些是平台自己制作的内容，但同样的逻辑在起作用：数字内容不存在物理载体上的“所有权”。

回到PlayStation案例，有趣的是索尼此前曾尝试安抚用户。2023年Discovery事件后，索尼约定了30个月缓冲期，当时也有用户存疑：30个月后呢？现在答案揭晓了。

数字删除与物理世界形成鲜明对比。如果你想确保永远保有一部电影，最可靠的方式依然是买一张蓝光光盘或DVD。尽管物理介质也可能磨损、未来可能没有播放设备，但至少没有人能从你的书架上把它拿走。

这件事之后怎么发展？目前看索尼没有退款的迹象。IGN联系索尼寻求评论，尚未得到回复。但考虑到2023年Discovery事件中索尼最终改口，不排除这次也会出现转机。不过，即便这次删除被暂停或取消，根本问题依然存在：数字购买的“所有权”根基不稳。

用户能做什么？现在唯一的建议是：检查你的PlayStation视频库，看看是否有名单上的电影。如果有，在9月1日之前看掉，或者尝试下载到本地。但即使下载，索尼部分内容可能有DRM保护，离开PlayStation环境可能无法播放。

更深层的问题是：我们是否应该继续购买数字内容，尤其是电影和游戏？2024年，育碧关闭了老游戏《飙酷车神》的服务器，导致购买了该游戏的玩家无法再游玩。随后玩家组织起来抗议，但无济于事。数字时代的消费者权利，依然是一个没有被充分保护的灰色地带。

索尼作为一家巨型娱乐公司，其游戏业务每年赚取数十亿美元利润。在2025财年，索尼整体利润达到75.35亿美元。但利润丰厚并不妨碍它做出这类让用户反感的决定。对于消费者而言，唯一可靠的应对方式可能只有一种：如果你真的在乎，就买实体版。

不过，实体版也在逐年萎缩。许多游戏不再推出实体版，电影发行也越来越依赖流媒体。未来我们可能别无选择。

这个故事没有完美的结局。索尼的删除按钮已经按下，倒计时已经开始。你账户里的电影，可能某天就会变成一行提示：“内容不再可用”。而你，除了接受，别无他法。
