# 林亦

AI博主林亦：从算法工程师到内容创业者的转型之路

点击播放 00:00 / 05:08

林亦的合伙人晓白，是后来加入的。他是个商业和资源整

你好，我是伊恩。今天，我们来聊聊一个特别的人，他叫林亦。你可能没听过这个名字，但如果你关注科技和AI，你很可能看过他的视频。他原本是个视觉算法工程师，却因为一场比赛，意外改变了人生轨迹。让我们一起走进他的故事。

2019年，林亦还是一家科技公司的视觉算法工程师。他参加了一场关于Deepfake的比赛，也就是AI换脸技术。他信心满满，觉得志在必得。结果，他输了。输得很惨，甚至影响了他的职业发展。这件事让他开始反思，自己到底适合做什么。也就是在低谷期，他开始尝试在B站发视频，记录一些数码相关的内容，算是一种自我表达。

一开始，他的视频很普通，就是开箱、测评，没什么人看。直到2021年，他做了一期关于苹果采访的视频，反响特别好。那是他第一次感受到，原来做内容也能获得这么大的满足感。后来，ChatGPT出现了，他敏锐地捕捉到这个风口，把频道方向转向了AI和技术开发。他的视频不再只是简单测评，而是挖掘技术背后的故事，比如他用30天写了一个完美的贪吃蛇AI，或者用AI写了个枪枪爆头的AI外挂。这些视频不仅吸引了大量观众，也让他在科技圈站稳了脚跟。

林亦的合伙人晓白，是后来加入的。他是个商业和资源整合的高手，跟林亦形成了完美互补。林亦负责技术，晓白负责商业化。他们从个人创作走向了几十人团队的公司，这中间当然有很多挑战。比如，如何平衡内容质量和商业变现。林亦说，他们最早接的都是数码产品的乙方项目，就是帮厂商做推广。但后来，随着频道影响力的提升，他们慢慢转向甲方市场，可以做更多自己想做的内容了。

听完林亦的故事，我想到一个问题：在这个信息爆炸的时

其实，林亦的经历不是个例。在整个视频内容行业，很多创作者都经历过从个人兴趣到商业化运营的转变。比如，早期的游戏主播，很多人也是从爱好出发，后来才签约平台，成为全职主播。再比如，知识区的一些UP主，也是先积累学术背景，再用通俗的方式分享专业知识。林亦的故事，其实是这个时代的一个缩影——技术改变不了世界，但讲故事可以。

林亦特别强调一点，就是观众的信任。他说，每次接商业合作，他都会想，这个广告会不会让观众觉得不舒服。他不想因为赚钱而失去观众的信赖。因为对他来说，观众才是真正的护城河。当平台流量见顶，消费电子进入下行周期，他更看重的是如何用AI、人才培养和资源连接能力，找到第二增长曲线。他想，也许未来可以做一个技术媒体平台，或者帮更多技术人做内容。

现在，林亦和晓白还在摸索。他们刚推出一个叫“皮蛋漫游记”的播客，专门聊科技和AI。他们说，希望能把这个频道做成一个品牌，就像机核一样，成为科技爱好者的大本营。但未来会怎样，谁也说不准。唯一确定的是，他会一直做下去，因为他热爱这件事。

林亦说，他不想做最懂技术的，但他想做懂技术里故事讲得最好的。这句话让我想了很久。也许，这就是他把算法工程师和内容创作者结合得这么完美的原因吧。技术是冷的，但故事是热的。他选择用热的故事，去包裹冷的技术，从而触达了更多人。

听完林亦的故事，我想到一个问题：在这个信息爆炸的时代，我们到底应该追求什么？是追逐流量，还是坚守价值？林亦给了我们一个答案：他选择了内容，选择了表达，也选择了面对真实的自己。也许，这就是他成功的原因吧。

好了，今天的故事就讲到这里。感谢你的陪伴，我们下次见。
