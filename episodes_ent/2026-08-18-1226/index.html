# 星际迷航

星际迷航的9/11阴影：一次虚拟灾难的紧急刹车

点击播放 00:00 / 06:03

其实，9/11对游戏行业的影响远不止这一款。Roc

你好，我是伊恩。今天的故事，要从2001年9月11日那天说起。那天早上，纽约双子塔倒塌的画面震惊了全世界，而就在那个时刻，加州一间游戏工作室里，几个设计师正盯着屏幕，一脸茫然。他们手中的项目叫《星际迷航：精英部队2》，一款基于经典美剧改编的第一人称射击游戏。根据主创Benson Russell的回忆，游戏原本的开场是星舰学院遭到袭击，一架穿梭机直直撞进大楼。他们花了几个月制作的场景，在那一刻突然变得刺眼。

9/11之后，几乎整个娱乐产业都陷入了混乱。电影推迟上映，游戏忙着修改内容，生怕触碰观众的伤疤。但Russell和他的团队没想到，他们精心设计的开幕，就是那个穿梭机撞大楼的镜头，竟然成了必须删除的对象。他说，“我们确实有一个穿梭机飞进大楼的镜头”，但那是“不行的，原因完全可以理解”。于是，他们连夜改剧本，把袭击者换成了外星敌人，把场景从地面搬到了太空。

这不是唯一被砍掉的内容。游戏里原本有一段发生在星舰学院的地面战斗，后来整个被简化成一段过场动画。Russell回忆，那段时间他们几乎每天都在开会，讨论哪些部分“太敏感”，哪些台词要重写。结果，游戏虽然在2002年6月发售，商业上不算成功，却意外成了粉丝心中的经典。原因之一，是它保留了《星际迷航》的精髓——对话、探索和道德选择，而不仅仅是爽快的枪战。

其实，9/11对游戏行业的影响远不止这一款。Rockstar的《侠盗猎车手3》就差点惹上麻烦。那款游戏设定在类似纽约的开放世界，原本的警车涂装模仿纽约警局，结果被逼改成普通警车。更夸张的是，游戏封面原本是一辆吉普车停在高楼大厦前，但为了避开敏感意象，Rockstar换成了现在这种网格状背景的封面。这张封面后来成了GTA系列的标志，一直用到今天的GTA6。

那么，站在今天的视角，我们怎么看待当年的改动？有些

所以，《精英部队2》的改动只是冰山一角。但让我好奇的是，为什么这些游戏非改不可？有人会说，那是出于政治正确。但在我看来，这是一种对现实创伤的尊重。游戏是娱乐，但在灾难面前，娱乐需要找到一个平衡点。就像电影《蜘蛛侠》2002年上映时，预告片里双子塔的镜头被删掉，海报也换了背景。

但这种敏感并非一直存在。早在1990年代，游戏里摧毁城市、撞大楼是常见桥段，玩家和媒体都觉得无所谓。比如1999年的《毁灭战士》玩家MOD，还有《雷神之锤》的地图，都有飞机撞摩天楼的恶搞内容。直到9/11之后，整个行业才意识到，虚拟世界的暴力可能会被现实事件激活。于是，开发者们开始自我审查，甚至主动创造新的叙事模式。

有趣的是，这种审查也促成了创新。当《精英部队2》被迫改掉开场，他们转向了更注重角色对话和谜题的设计。游戏里有一段皮卡德舰长的演讲，和原作剧集一脉相承。玩家可以感受到，在危机中，英雄不是靠枪而是靠智慧。这让我想到，90年代的《星际迷航》游戏，比如《星际迷航：航海家号-精英部队》，更注重战斗，而《精英部队2》却试图在战斗中加入人文关怀。这种转变，直接影响了后来《质量效应》这类游戏的发展。

现在，距离9/11已经过去二十多年，游戏业对敏感内容的处理更加成熟。但每当有灾难发生，比如新冠疫情，游戏公司还是会调整发布计划。我记得2020年《最终幻想7重制版》就推迟了，因为某些内容太贴近现实。

那么，站在今天的视角，我们怎么看待当年的改动？有些人觉得，那是懦弱的表现，艺术不应该被现实绑架。但另一些人认为，正是这种克制，让游戏在情感上更贴近玩家。我记得《精英部队2》的导演Russell后来在采访中说，如果当时没改，那个穿梭机撞大楼的镜头可能会让玩家感到不适，甚至引发创伤。他并不后悔。

好吧，这就是今天的故事。一款因为现实而改变命运的游戏。我们总说，艺术源于生活，但有时候，生活也会粗暴地打断艺术。也许，《精英部队2》的改动，只是一个时代的注脚，提醒我们，游戏不仅是娱乐，也是时代的镜子。当虚拟世界与真实历史碰撞，我们总会找到新的方式去讲述故事。好了，我对你还有什么想说的呢？
