# 游戏保护

90张显卡，救回一款消失的FF7外传

点击播放 00:00 / 08:34

2018年，Square Enix正式关闭这款游戏

你好，我是伊恩。今天想跟你聊一个数字：900美元，90张显卡。听起来像某个加密货币矿场的配置，但其实是有人为了救回一款已经死了八年的手游。这款游戏叫《地狱犬的挽歌：失落章节》，是《最终幻想7》衍生作品《地狱犬的挽歌》的手游外传。它2006年上线，2018年服务器关闭，从此变成数字废墟。直到今年，一个叫Yuvi的玩家黑客，用一笔不算多的钱和一堆显卡，硬是把这堆数据从加密的坟墓里刨了出来。

先把事情讲清楚。2006年，手机游戏还处在远古时代，屏幕小、功能少，但Square Enix已经想试水了。他们做了一个只给Amp'd Mobile网络用户玩的手游，这个运营商现在早就没了，当年也只在北美部分地区运营。游戏是《地狱犬的挽歌》的延伸，主角文森特·瓦伦丁继续追杀敌人，有配音、有剧情，甚至还有3D画面，放在那个年代算得上豪华。但问题是：它锁在了一个小众的运营商网络里，受众本来就少，几年后Amp'd Mobile破产，游戏自然就下架了。Square Enix也没做移植，就这么把它扔进了历史垃圾堆。

2018年，Square Enix正式关闭这款游戏的服务器，联网功能全废，单机部分也因为授权和密钥问题没法运行，游戏彻底死了。但数字世界有个特点：只要数据还在，就总有复活的机会。2024年，Yuvi搞到一张加密的SD卡，里面存着游戏的全部文件，包括3D模型、关卡脚本、配音音频，甚至还有服务器端的逻辑代码。问题在于加密——没有密钥，这些文件就是一堆乱码。Yuvi说，他花了两年的时间去找密钥，联系Square Enix，查公开资料，都一无所获。他说：“我受够了，我们手上有数据，只是解不了锁，那就自己想办法。”

他开始了破解工程。加密算法并不罕见，但密钥强度很高，用普通电脑跑，可能要几个月甚至几年。Yuvi一开始用了点技巧，试着找漏洞，但进展太慢。于是他说：“我搞了个GPU农场。”他花了900美元，租用或调集了超过90块显卡，包括RTX 4090、A4000、A4500、A5000、RTX 6000，甚至还有H200这种数据中心级别的加速卡。这些显卡拼在一起，疯狂运算，试图暴力破解密钥。硬件的算力是惊人的：原本预计要跑几个月的任务，几天就完成了。密钥被找到，文件被解锁，游戏成功运行。Yuvi在YouTube上传了演示视频，画面里是文森特熟悉的红色披风，在粗糙但完好的3D场景中移动，语音清晰，操作流畅。这一瞬间，一款死了八年的游戏复活了。

这背后的意义，远不止一款冷门手游被救回来。游戏保护，一直是游戏行业的老大难问题。实体时代，卡带和光盘至少能留存几十年，但数字时代，游戏依附于服务器和在线服务，一旦商家关停，玩家手里的东西瞬间变成砖头。很多游戏就这么消失了，尤其是手游。根据“游戏历史基金会”的统计，超过80%的经典手游已经永远无法游玩。Square Enix自己就是“游戏杀手”：从PS2到手机，他们旗下的经典作品至少有十几款因为授权过期或硬件淘汰而永远封存。

Yuvi不是第一个尝试拯救消逝游戏的人。2019年，玩家们发起“漫威英雄”的私服计划，这款网游在关服最后一天被粉丝抓包，数据被完整保存，后来通过模拟服务器重开。2021年，一群爱好者用手机模拟器重制了《索尼克大冒险》的取消版本“索尼克Xtreme”，让一个从未发售的游戏首次可玩。更早期的例子是“蓝杰计划”，一群玩家花了数年时间破解N64平台《塞尔达传说》的未完成版本，最终在2019年放出了可运行的原型。但像Yuvi这样，为一个冷门手游砸钱砸时间，甚至自建GPU农场破解加密的，并不多见。

这件事还牵出更深层的行业问题。开发商和发行商一直在用法律和数字版权管理（DRM）来限制游戏的使用和保存。当游戏的生命周期结束，他们可能会考虑将数据归档，但大多数时候，他们只是关掉服务器，甚至会因为版权争议而阻止玩家保存。Square Enix在2024年还关掉了《最终幻想7：永恒危机》手游，这款游戏本来打算作为系列前传，结果运营不到一年就没了。玩家们经常开玩笑说，Square Enix最擅长的是创造经典，第二擅长的是把经典埋进土里。但讽刺的是，正是这些“违法”玩家和黑客，成了游戏历史真正的守护者。

游戏保护业界对此看法不一。支持者认为，这些努力是必要的，因为商业公司决策层可能不了解游戏的文化价值，而玩家是真正的热爱者。反对者则担心，破解加密可能涉及法律风险，甚至可能被利用传播恶意软件。法律专家指出，美国《数字千年版权法》第1201条禁止绕过访问控制技术，但图书馆和档案馆有豁免条款。不过，像Yuvi这样的个人行为，依然处在灰色地带。

但这种行为的意义，已经超越了单个游戏。Yuvi在博客里写道：“这些游戏不是产品，是文化。如果我们不保存它们，未来的人就再也看不到昨天的人们在做什么。”他的行动，是对数字时代“遗忘”的抵抗。与此同时，Square Enix似乎也在尝试回收这些旧作品的资产。在《最终幻想7重制版》三部曲中，制作人引用了《地狱犬的挽歌》的剧情元素，而在柏林粉丝节上，导演滨口直树提到，他们正计划把更多外传的设定融入新作《启示录》。这说明，商业公司也在寻找自己的方式，让这些草稿重见天日。

回到Yuvi的这次成功，我想到一个更大的问题：我们到底该如何对待数字时代的遗产？我们写下的文字，拍下的照片，玩过的游戏，都只是储存在那些庞大的数据中心里，像待解的密码。也许，在未来的某一天，我们会需要一个一个GPU农场，去唤醒这些沉睡的记忆。那些漫长而孤独的破解过程，就像为冰冷的二进制数据注入生命力。玩家们在屏幕前尖叫，人工智能默默推演，而真正在驱动这一切的，是人对于曾经热爱之物的执念。

Yuvi的演示视频现在还在他的YouTube频道上，播放量不高，但评论区里满是感谢。“终于等到你”“谢谢你，我哭了”“这是给所有游戏人的礼物”。对我来说，这个故事的魅力不在于技术多酷，而在于，有人愿意为一个已经消失的世界，花900美元和一腔孤勇。这提醒我，在这个按下删除键就永别的时代，总有人愿意拒绝删除。
