# 停止扼杀游戏

游戏不能死：加州法案背后的十年抗争

点击播放 00:00 / 10:34

育碧不是第一个这么干的。2019年，迪士尼就关闭了

你好，我是伊恩。今天早上，加州议会以43比16通过了一项法案，要求游戏公司关服前必须提前60天通知，并给玩家留条活路。你可能觉得这只是个新闻，但为了这一刻，一群人已经吵了十年。

《The Crew》是育碧在2014年推出的一款开放世界赛车游戏。你开着车横穿美国，从洛杉矶一路飙到纽约，沿途风景变换，和朋友们组队竞速。这款游戏卖了几百万份，不算顶级大作，但有自己的忠实玩家群。2023年底，育碧突然宣布，《The Crew》将于2024年3月31日停服，届时游戏将从所有数字商店下架，已经购买的玩家也无法再进入游戏。玩家们炸了锅。你花了60美元买的东西，说没就没了？育碧的理由是服务器维护成本高，而且他们想集中资源搞续作。但玩家不买账：你卖的时候可没说过这游戏是有保质期的。更狠的是，停服之后，连单人模式也玩不了，因为所有数据都存在育碧的服务器上。好比你买了一辆真车，厂家却说，十年后我们收回这车的发动机，你就推着走吧。

育碧不是第一个这么干的。2019年，迪士尼就关闭了《迪士尼：无限》的服务器，那可是个实体玩具加数字游戏的混合体，玩家花大价钱买的玩具瞬间变废塑料。2021年，索尼关了《驾驶俱乐部》的服务器。2022年，任天堂下架了《火焰之纹章：英雄》的离线模式。2023年，EA停掉了《战地风云1943》的线上服务。这些游戏被做成了漂漂亮亮的数据墓碑，墓碑上刻着发行日期和死亡日期。玩家们愤怒，但愤怒完也就散了，直到《The Crew》事件彻底戳到了痛处。

反对的声音当然很大。商业软件联盟代表微软、育碧、E

有个叫罗斯·斯科特的YouTube博主，专门做游戏评论，频道叫“Accursed Farms”。2024年4月，他发起了一个叫“停止扼杀游戏”的运动。这个运动的核心诉求很简单：游戏公司不应该在玩家购买后又悄无声息地把游戏弄死。斯科特的想法迅速发酵，几个月内，他们在Change.org上收集了超过40万个签名。他们的目标很明确：推动立法，从法律上要求游戏公司为停服游戏提供补偿或离线版本。

运动很快从线上走到了线下。2024年秋天，“停止扼杀游戏”的志愿者开始联络政界人士，最终美籍华裔加州众议员克里斯·沃德注意到了这个议题。沃德的选区里有不少游戏从业者，他自己也玩《马力欧赛车》。几个月后，沃德正式提交了AB-1921号法案，也就是后来的“保护我们的游戏法案”。

法案的内容拆开来看，其实不复杂：任何在加州销售的服务型游戏，如果开发商要关闭服务器，必须提前60天通知玩家，而且必须提供至少一条后路——要么是让玩家可以自己搭建私人服务器继续玩，要么给离线版本，要么干脆退款。违者面临罚款，公司有可能被起诉。

反对的声音当然很大。商业软件联盟代表微软、育碧、EA等大公司游说加州议员，说这会扼杀游戏行业的创新。他们的逻辑是：服务型游戏是时代的趋势，如果强制要求停服后维持可玩性，会大幅增加成本，很多小开发者根本负担不起。沃德的回应很有意思，他说：“游戏不是为了打破之后才卖出去的。”他引用了一个数据：每年全球有超过200款服务型游戏停服，其中一半在运营不满两年。如果买游戏真等于租游戏，那开发商至少该告诉玩家你这东西是租来的。

the Crew事件不是孤例，它是2010年代以来游戏产业变迁的一个缩影。2009年，街霸4和使命召唤：现代战争2让在线游戏卖了几千万份，但从始至终玩家都知道自己买的是能独自游玩的软件。2013年，微软在Xbox One发布会上犯了一个致命的错误：他们试图规定所有游戏必须时刻联网，而且二手交易将被限制。玩家们愤怒到极点，微软最终完败，收回了政策。那一次，玩家赢了。但此后的十年里，行业悄悄走了另一条路。

2014年起，越来越多的厂商开始只做下载版，包月订阅制也渐渐流行，玩家逐渐丧失了对一款游戏的所有权。你买的其实不是游戏，而是某个访问权。就像Steam其实只卖许可证，Uplay更是把用户协议写得比词典还厚。到了2020年代，连单机游戏也常常需要联网才能玩，因为反盗版或成就系统必须联网。

游戏的法律定义在国际上长期模糊。在美国，游戏被视为“软件”，受版权法保护，但版权法并未明确规定消费者享有永久使用权。EULA，也就是最终用户许可协议，实际上允许厂商随时收回你的游戏权。每年都有玩家购买的游戏停服，但只有少数人会真的起诉。2018年，有玩家因《GT赛车》联网关服集体起诉索尼，法院却以“玩家已同意用户协议”为由驳回了。不过1988年，美国有个标志性案件叫做路易斯诉加州，确立了“消费者有权合理使用所购产品”的精神，但它从未被直接适用在数字商品上。

加拿大1988年在《消费者保护法》里隐约涉及了“数字商品永久性”的概念，欧盟2022年的数字市场法也间接允许用户自主搭建服务的可能性。不过真正最接近的，是2023年法国国会议员提出的一项法案草案，要求所有“在线游戏”必须保证停服后仍能游玩离线版本。那个草案当年被驳回了，理由是“会阻碍创新”。

“停止扼杀游戏”本质上是一个消费者保护运动，关涉的是权利，也是文化。游戏已经被联合国教科文组织认定为文化遗产，但实际操作中，没人管。任天堂、世嘉在1980年代生产的卡带现在依然能运行，可2030年代的玩家可能再也玩不到2010年代的代码了。数字时代加速了这种消失：据数据统计，2008年至2023年间，互联网上已有超过30%的在线游戏彻底消失，超过60%的数字购物的商品逐渐消失或者无法再次访问。人类对数字物品的所有权，正在被科技巨头悄悄抽走。

AB-1921的通过是一个巨大胜利。但它还远没结束。下一步，法案还要在加州参议院通过，然后由州长签字才能生效。就算全通过，也仍然只覆盖加州一个州。加州的玩家连上了服务器，但得克萨斯、佛州的玩家怎么办？而且大型游戏公司真的会安安静静地赔钱吗？

在加州投票的当天，育碧没有立即回应。但据消息人士透露，EA内部已经开了好几次紧急会议，讨论是否在新游戏中加入离线保证。索尼不久前还宣布，要关停一款刚发售半年多的PS5游戏服务器。2K则刚刚下架了乐高2K赛车。所以这道法案，是在考验整个产业。

议员沃德的智囊团给出的预测相对悲观：如果最终通过，初期可能会有更多小型游戏在发售前直接声明“我们可能随时停服”，反而让玩家更警惕。但这总比现在闷声扼杀好。斯科特自己倒是乐观得多，他说：“我们证明了只要玩家团结起来，可以改变世界上最庞大的产业之一的规则。”

至于那些坚持了几年的运动志愿者，很多人反而对后续发展有点恐惧。游戏的商业模式正从一次性买断转向长期服务，这会彻底改变行业形态，短时间恐怕会带来更多关服先例。现在的《TheCrew》已经停服一年多了，当年那位愤怒的玩家可能早就死了心。但如果没有他，没有40万个签名，没有加州43票对16票的胜利，这盘棋可能永远没人敢下。

数字世界的命运，从来没有那么简单过。以后你会买到更多随买随关的游戏吗？不一定。但至少，有人开始认真思考该怎么做了。

（深呼吸）

加州这个法案也许并不完美，但它让很多游戏从业人员意识到，那个既想让玩家掏钱又想让游戏永远消失的商业模式，已经不被容忍了。技术、金钱、文化，这些全都纠缠在一起。我们买的不仅仅是一串代码，还是自己在这段数码时光里的记忆。记忆不该被轻易删除，你说呢？

好，我是伊恩，这篇故事的脚步先到这儿了。
