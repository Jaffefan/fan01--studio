# EA

EA被沙特收购：电子游戏业的权力游戏

点击播放 00:00 / 09:00

EA，这家公司，你可能不熟悉它的名字，但你一定知道

你好，我是伊恩。今天，电子游戏业迎来了一次大地震，但消息传出来，却感觉像是闷雷滚过，好多玩家还没反应过来。电子艺界，简称EA，正式卖身了。五十五亿美元，买家不是科技巨头，不是传统媒体，而是一个由沙特阿拉伯公共投资基金、银湖资本，还有杰瑞德·库什纳的亲和力合伙公司组成的联合体。这笔交易在今天股市收盘后正式完成，成为游戏史上第二大收购案。你可能还记得，之前微软收购动视暴雪花了六百八十七亿，那是史上最大。现在，老二出现了，但它的买家组成，却比金额本身更耐人寻味。

事情的开端，要追溯到去年九月。当时，EA的股东们得到了一个惊人的消息：公司即将被收购。消息一出，股价应声而涨，但紧接着，各种疑虑就涌了上来。首先，联合体的成员构成非常蹊跷，沙特公共投资基金，那是沙特王储穆罕默德·本·萨勒曼掌管的公共投资基金，资产总额估计有九千亿美元，是沙特用来推进经济多元化的核心工具。银湖资本，那是知名的科技投资公司，一直在科技界深耕。而最让人意外的，是亲和力合伙公司，它的老板，是特朗普的女婿，杰瑞德·库什纳。

当时很多人就觉得，这个组合怎么这么怪？后来媒体披露，这笔交易里，沙特公共投资基金将持有EA百分之九十三的股份。没错，百分之九十三。也就是说，尽管名义上是三家联合收购，但真正的控制权，其实落入了沙特王储的手中。这消息一出来，舆论炸了锅。但更让玩家愤怒的，可能是EA旗下那些经典游戏系列的命运。

EA，这家公司，你可能不熟悉它的名字，但你一定知道它的游戏。《模拟人生》，那个让无数玩家创造虚拟人生的游戏系列，从二零零零年第一代发布至今，已经卖出了超过两亿份。《战地》，现代战争射击游戏的代表。《FIFA》，全球最畅销的体育游戏，每年都出新作，无数球迷在虚拟绿茵场上竞争。这些系列，都是EA的摇钱树，也是无数玩家的青春记忆。然而，这家公司，现在归沙特了。

但如果你以为，这只是沙特有钱任性，随便买买买的又一次操作，那你就小看这盘棋了。这背后，其实是沙特阿拉伯近年来在游戏和电竞领域雄心勃勃的布局，也是全球资本在娱乐产业上的一次重新洗牌。我们来回头看看沙特公共投资基金这些年在游戏圈的足迹。早在二零二零年，这个基金就买下了日本的SNK，那家公司出过《拳皇》，还有《合金弹头》。到了二零二三年，他们又收购了《怪物弹珠》的开发商Mixi的股份，还投了《原神》的开发商米哈游。去年，他们更是把《漫威突击队》的开发商Scopely纳入囊中，据传交易金额在四十九亿美元左右，那款《MONOPOLY GO!》就是他们家的，赚得盆满钵满。还有Niantic，那个出了《宝可梦GO》的公司，他们也有股份。更别提他们对任天堂、Take-Two Interactive这些行业巨头的投资了。

你会发现，沙特的策略，不是漫天撒网，而是精准打击。他们瞄准的，都是拥有庞大用户基数和成熟IP的公司，尤其是那些在欧美市场有深厚影响力的。为什么？因为沙特王储的“愿景2030”计划，目标就是让沙特经济不那么依赖石油，发展娱乐和旅游产业，而电子游戏，在全球吸引了三十多亿玩家，正是他们眼中的金矿。

但沙特的入局，止不住的争议也随之而来。说到这，你可能会问，那EA的雇员们怎么看？玩家们怎么看？据媒体报道，早在交易宣布时，EA内部就炸锅了。一些雇员对媒体表示，他们对公司被沙特收购感到愤怒和不安，尤其是考虑到沙特的人权纪录。你可能听过，沙特在西方媒体的报道中，经常被描绘成对人权问题毫不含糊的形象。国际特赦组织指出，沙特阿拉伯近年执行死刑人数创下纪录，还限制女性权利，歧视LGBTQ+群体。而EA旗下偏偏有《模拟人生》这样以多元和包容著称的系列，这个系列向来在性别表达和性向平等方面走在前列。游戏里的角色可以自由定制性别、取向，甚至有人用它来模拟同性婚姻，在那个虚拟世界里，玩家可以自由做自己。但现在，一个把同性恋定罪的国家的政府基金，成了这个游戏系列的最终老板，这讽刺感，让不少玩家心里不是滋味。

更让人担忧的是，这笔交易可能带来的实际影响。有分析师警告，EA可能因为债务压力而关闭一些工作室，比如那个曾经打造了《质量效应》和《龙腾世纪》的BioWare。BioWare以剧情和角色塑造见长，但近些年成绩不佳，一直在裁员边缘挣扎。一旦被沙特控制，商业利益导向或许会更极端。另外，EA的股票将退市，这意味着它不再需要定期公布财务报告，它的运营将成为黑箱。分析师、投资者，还有媒体，都很难再准确知道EA内部发生了什么。这对整个行业的透明度，都是一个打击。

但我们不妨把目光再拉远一点。沙特买下EA，这并不是一个孤立事件。实际上，如果你仔细看，你会发现，全球游戏产业，正在被地缘政治和资本大鳄重新瓜分。过去几年，我们见证了微软对动视暴雪的收购，索尼也在不断收购独立工作室，腾讯投资了无数游戏公司，亚马逊、谷歌这些科技巨头也试图在云游戏领域插一脚。而沙特公共投资基金，就是其中一只最凶猛的掠食者。他们不差钱，背后的国家意志又坚定，目标也明确。

这让我们不得不思考，当国家主权基金成为游戏公司的大股东，对游戏玩家来说，到底意味着什么？对游戏从业者来说，又意味着什么？也许，这只是全球游戏产业“沙特化”的一个开始。而在今天，这笔交易落下帷幕，EA的大门向一个新东家敞开。但门后的世界，究竟是更繁荣，还是更寒意逼人，没有人真正知道。

有业内人士指出，游戏本质上是文化产品，它承载了故事、情感和价值观。当一个文化产品的控制权落入一个与自由表达和多元价值观相悖的政府手中，它自由创作的灵魂还能不能延续？也许，新东家会入乡随俗，让《模拟人生》继续自由发展，也许，他们会为了利润最大化，让那些他们看不惯的内容悄悄消失。在一切尘埃落定之前，我们只能静观其变。

但有一点可以肯定，电子游戏，已经不再是那个只属于极客的亚文化，它已经变成了资本逐鹿的战场，变成了大国角力的筹码。EA只是其中一个缩影。或许未来，我们会看到更多游戏公司被类似的财团收购，看到游戏的内容因为资本的偏好而改变。这对玩家来说，是福是祸，也只能自己去体会了。
