# id Software

id Software裁掉一半人，FPS祖师爷还剩什么？

你好，我是伊恩。今天聊一个让人有点唏嘘的消息——老牌FPS工作室id Software，裁掉了将近一半的员工，95个人。而且裁掉的不是别的，几乎全是技术骨干。

消息是从Game Developer传出来的。id Software在Xbox最新一轮大规模裁员中遭遇重创，截止发稿前已经解雇了大约95名员工，占团队总规模的一半。裁员主要集中在程序员、QA人员以及工具开发等技术岗位，其中包含多位入职超过10年的资深开发人员。首席概念艺术家Colin Geller也确认被解雇。

3D Realms的联合创始人George Broussard在社交媒体上说，id Software核心团队幸存者现在只剩管理层、美术和设计人员，这让id Software作为开发工作室已经“名存实亡”。他判断，id Software未来的定位更像是为贝塞斯达其他工作室提供协助的辅助工作室。

这可不是个普通的工作室。id Software是《毁灭战士》《雷神之锤》的缔造者，是FPS这个游戏类型的奠基人。他们自主研发的id Tech引擎，从初代《毁灭战士》开始就不断迭代，至今已发展到id Tech 7。但这次裁员后，行业分析普遍认为，id Tech引擎的发展与维护将严重受损，很可能会被放弃，转而采用Epic的虚幻引擎。

还有一个更具体的后果：受此次裁员影响，《毁灭战士：黑暗时代 启示录》很可能成为id Software在未来很长一段时间的最后一个项目。尽管Xbox计划在未来将更多精力投向《毁灭战士》及《雷神之锤》等IP，但几乎所有技术骨干的离职，让这些项目的开发前景变得相当不明朗。

这件事让我想起2019年，id Software的联合创始人John Carmack离职时的情景。Carmack在1991年与John Romero等人共同创立id Software，他负责引擎技术，是游戏引擎开发史上的传奇人物。2013年他加入Oculus VR，专注于虚拟现实，但同年就从id Software董事会辞职。2019年，他完全离开id Software，表示“我在id的时代已经结束了”。Carmack的离开，被很多人看作是id技术灵魂的出走。

其实id Software的历史，就是一部FPS技术的发展史。1993年的《毁灭战士》用伪3D技术创造了惊人的快节奏射击体验；1996年的《雷神之锤》首次实现了真正的3D引擎，包括实时三维渲染、网络对战；1999年的《雷神之锤3》又引入了高端图形效果。之后id Tech引擎不断进化：2004年的《毁灭战士3》使用id Tech 4，以动态光影著称；2011年的《狂怒》使用id Tech 5，主打大规模开放世界；2016年的《毁灭战士》重启版使用id Tech 6，回归快节奏暴力美学；2020年的《毁灭战士：永恒》使用id Tech 7，把优化和特效推到新高度。

每一次id Tech引擎的更新，都推动着整个行业的技术进步。但这家公司的命运，从被收购开始就发生了转变。2009年，ZeniMax Media收购了id Software；2021年，微软收购ZeniMax，id随之归入Xbox游戏工作室旗下。大公司旗下的工作室，往往要服从整体战略。Xbox近年来的策略明显倾向订阅服务Game Pass和跨平台策略，对技术和引擎的独立研发投入可能不如从前。

更早的历史还有：1996年，id Software的灵魂人物之一John Romero因理念不合离开，随后创办了Ion Storm，但再也没有达到id的高度。那次分裂当时也引发了对id未来的担忧，但Carmack还在，技术核心没丢。这一次，连技术骨干都几乎被裁光，情况完全不同。

把视角拉远，这不是孤立事件。整个游戏行业最近两年都在经历“技术裁员潮”。2023年，Epic Games裁员830人，其中很大一部分是虚幻引擎的技术团队；同年，Unity裁员近300人，并进行业务重组；2024年，微软Xbox部门裁员数千人，四家第一方工作室被剥离。在这种大环境下，技术团队往往首当其冲，因为他们的成本高、产出慢，不像美术和设计可以直接体现在内容上。

另一个对比案例是CD Projekt Red。他们在《赛博朋克2077》发售后，也经历了技术团队的大换血，并决定抛弃自家引擎REDengine，转向虚幻引擎5。如今他们正在用虚幻5开发《巫师》新作。Halo Studios也在2024年宣布放弃Slipspace引擎，转用虚幻5。但这两家公司至少还有完整的核心团队，而id Software这次是连引擎的创造者都没了。

现在舆论场上有几种声音。一种是可惜——这样的老牌工作室，技术底蕴和品牌价值都极高的团队，就这么被架空，很多人觉得微软的策略短视。一种是冷静——认为在商业逻辑下，大公司收购后整合资源是常态，id作为辅助工作室可能更符合Xbox的“平台思维”。还有一种是悲观——认为引擎技术本来就是为了服务游戏，如果《毁灭战士》新作能用虚幻引擎做出更好的效果，那放弃id Tech也许不是坏事，但前提是留下来的团队还能做出好游戏。

至于我的看法？我不喜欢“名存实亡”这个词，它的分量太重了。但或许，id Software真的进入了一个新阶段——从开创者变成协作者，从技术驱动变成IP孵化器。这未必是坏事，但确实有点冷。
